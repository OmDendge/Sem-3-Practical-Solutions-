# Module 3 – Question 3: FrameLayout, TableLayout and RelativeLayout

- **RelativeLayout** positions the header and content relative to other views.
- **TableLayout** arranges forecast values in rows and columns.
- **FrameLayout** stacks children; the Refresh button is overlaid on the table area.
- In modern projects, ConstraintLayout is often preferred for complex responsive screens.
