# Module 3 – Question 4: Student information form

The screen contains username, password, address, gender RadioGroup, numeric age, DatePickerDialog, State Spinner and Submit button. On submit it validates required fields and prints all entered values beneath the button.

**Controls used:** EditText, RadioGroup, RadioButton, Spinner, Button, TextView and DatePickerDialog.

**Note:** Password is collected only to satisfy the stated form question; do not print or log passwords in a real application.
