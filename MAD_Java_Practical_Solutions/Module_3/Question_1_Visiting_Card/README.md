# Module 3 – Question 1: Visiting Card
**Aim:** Create a business card with logo at top-right, centred uppercase company name, employee details and a horizontal divider between designation and contact information.

The supplied XML uses ConstraintLayout for responsive positioning. Replace the sample logo (`@mipmap/ic_launcher`) with your own drawable resource and update the sample employee/contact details. The company name is centred; the logo is aligned to the top-right. The horizontal `View` is the divider.
