# Module 1 – Question 1: Hello World
**Aim:** Display “Hello World” at the centre, red text on a white background.

**XML:** `activity_main.xml` places a TextView using ConstraintLayout constraints on all four sides, which centres it horizontally and vertically.

**Java:** `MainActivity.java` loads the XML layout. No runtime permission is required.

**Expected output:** White screen with red “Hello World” centred.
